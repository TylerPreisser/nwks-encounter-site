# Project map — nwks-encounter-site

**The authoritative map for this project is the `## Project context` section of the repo's
root `CLAUDE.md`** — stack, surfaces, deployed-branch map, live system of record, build/deploy
commands, test layers, ground truth for *verify*, branch convention, code-graph status, and the
environment gotchas that have each cost someone real time.

It is deliberately kept in one place rather than duplicated here, because two copies of a project
map drift and then you can't tell which one lied to you.

Read `CLAUDE.md` → **Project context** for any "where is X / how is Y deployed / how do I know this
worked" question. If a fact there turns out to be wrong or stale, **fix it there** — that file is
the single source of truth for this project's wiring.
